# Navo Vyapar Asset Pipeline

This directory holds game assets organized by category. All visual and audio elements can be customized by dropping high-resolution files into their respective folders.

```
assets/
├── board/          # Board texture backdrops, wood grain, Gujarati corner filigree
├── cities/         # City illustrations (Ahmedabad, Surat, Vadodara, Rajkot, etc.)
├── properties/     # Property card badges and architectural icons
├── tokens/         # Custom 2.5D player token pawns
├── dice/           # Custom 3D dice textures / spritesheets
├── cards/          # Event & Samachar card illustrations
├── currency/       # Navo Bank Rupee ₹ notes & coin textures
├── ui/             # Buttons, dialogue frames, modal backdrops
├── icons/          # Category glyphs (Diamond, Textile, Heritage, Port, Tech)
├── backgrounds/    # Tabletop textures (Sheesham, Rosewood, Mahogany, Velvet Felt)
├── audio/          # Optional high-fidelity audio overrides (.mp3 / .ogg / .wav)
└── effects/        # Particle sprites and celebration bursts
```
